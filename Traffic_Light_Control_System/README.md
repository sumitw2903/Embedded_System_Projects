# Traffic Light Control System using ESP32

## Project Overview
This project simulates a traffic light system using an ESP32 and three LEDs.

## Components Used
- ESP32 DevKit V1
- Red LED
- Yellow LED
- Green LED
- 220Ω Resistors
- Breadboard
- Jumper Wires

## GPIO Connections
LED         GPIO
Green  ->   2
Yellow ->   4
Red    ->   22

## Working Principle
1. Green LED turns ON for 5 seconds.
2. Yellow LED turns ON for 2 seconds.
3. Red LED turns ON for 5 seconds.
4. The sequence repeats continuously.
